AtomicDropdown

A menu built on AtomicPopover — same trigger / placement / offset / disabled API, plus an items input and an optional appMenuitemTemplate slot.

Keyboard: the menu takes focus when it opens. ↓ ↑ move between items (skipping disabled ones), Home / End jump to the ends, Enter / Space activate, Tab closes.

Last action: {{ lastAction() }}

Basic

Disabled items

Disabled entries are marked aria-disabled and skipped by the arrow keys.

Items without onClick

They still close the menu, so a click never feels like it got stuck.

Who closes the menu — decided by onClick's arity

A 1-arg onClick closes the menu automatically. A 2-arg one receives close and decides for itself — the first item never closes, the second one does.

Component-level disabled

The whole menu refuses to open, and the trigger reports aria-disabled.

appMenuitemTemplate slot

Custom markup per item. The template receives label, value, disabled and the item's own context.
