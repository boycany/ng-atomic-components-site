AtomicDropdown

A menu list built on top of AtomicPopover — same trigger / placement / offset API, plus an items input that renders each entry as a <button>.

Last action: {{ lastAction() }}

Basic

Disabled items

Disabled entries stay rendered but their onClick is a no-op.

Manual close (2-arg onClick)

A 1-arg onClick closes the menu automatically. A 2-arg one receives close and decides for itself — the first item never closes, the second one does.
